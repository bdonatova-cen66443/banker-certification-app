# banker-certification-app

Moderní React + Vite hodnocení pro závěrečnou certifikaci bankéře, připravené pro GitHub Pages.

## Spuštění v development režimu

1. Nainstalujte závislosti:

```bash
npm install
```

2. Spusťte vývojový server:

```bash
npm run dev
```

3. Otevřete URL, kterou vypíše Vite (standardně `http://localhost:5173`).

## Vytvoření produkční verze

```bash
npm run build
```

## Publikace na GitHub Pages

Tento projekt je nastaven s `base` cestou `/banker-certification-app/` v `vite.config.js`.

```bash
npm run deploy
```

## Aktualizace nasazení

Po změnách spusťte:

```bash
npm run build
npm run deploy
```
